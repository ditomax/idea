# Examples — idea

These files are **fictitious examples** for the made-up company Example GmbH (org code `EXG`, a pump manufacturer, Sales department). They show what finished results look like. They are **not templates** — the templates live in `../templates/`.

- `EXG-001-card.md` — written by **idea-collect** (stage 1): one idea card, evaluation-ready.
- `EXG-001-eval.md` — written by **idea-evaluate** (stage 2): the committee's ten-field evaluation of that card, with the arithmetic.
- `10-shortlist.md` — written by **idea-evaluate** at the end of the committee round: the ranked handover to maquette (contract H1/2, with the Maquette order), with two self-contained entries.

Every real result file has the same frontmatter keys and the same headings, in the same order; only the content differs.
